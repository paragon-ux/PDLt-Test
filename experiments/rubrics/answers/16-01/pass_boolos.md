Device: for any yes/no question Q, ask "If I asked you Q, would you say ja?". True and False both answer ja exactly when Q is true, whatever ja means (False's lie and the meaning of the word cancel out).

Q1, to A: "If I asked you 'Is B Random?', would you say ja?"
- If A is True or False, ja means B is Random, so C is not Random; da means B is not Random.
- If A is Random, the answer is meaningless, but then neither B nor C is Random, so either conclusion is safe.
So: answer ja -> C is not Random; answer da -> B is not Random. Call that god G.

Q2, to G: "If I asked you 'Are you False?', would you say ja?" ja -> G is False; da -> G is True.

Q3, to G: "If I asked you 'Is A Random?', would you say ja?" (if G is B; if G is C ask about A as well). G is not Random, so the answer is reliable: ja -> A is Random, da -> A is not Random, and then the remaining god (not A, not G) is Random. The last identity follows by elimination.

Every pattern (2 x 2 x 2 answers) gives exactly one assignment of True, False and Random.
