FIND the median of the two sorted arrays nums1 and nums2 in O(log(min(m, n))) time using a binary search that partitions both arrays simultaneously.
VERIFY the implementation with the following test cases:
- nums1 = [1, 3], nums2 = [2] → expected median = 2.0
- nums1 = [1, 2], nums2 = [3, 4] → expected median = 2.5
- nums1 = [], nums2 = [1] → expected median = 1.0
- nums1 = [1, 3, 5, 7, 9], nums2 = [2, 4, 6, 8, 10] → expected median = 5.5
