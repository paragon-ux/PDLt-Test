User Story 1: As a user, I want to be able to search for products by name so that I can quickly find the items I am looking for.

User Story 2: As a user, I want a dashboard element that shows my recent orders and recommends similar products based on my purchase history, so that I can discover items I may be interested in.

User Story 3: As a user, I want a product detail view that displays real‑time inventory levels across all warehouse locations and allows me to reserve items for up to 24 hours, so that I can secure the product I intend to purchase.
