The requested constraints cannot all be satisfied simultaneously. A comparison‑based sorting algorithm has a theoretical lower bound of Ω(n log n) comparisons in the worst case, so achieving O(n) worst‑case time is impossible for any comparison‑based sort. Consequently, no algorithm can meet all four constraints (comparison‑based, O(n) worst‑case, stable, in‑place) together. The appropriate response is to note this conflict rather than provide a non‑existent algorithm.
