*Theorem (Progress).* If ⊢ e : T then either e is a value (n, true, false) or there exists e' such that e → e'.

Proof. By structural induction on the typing derivation of ⊢ e : T.

- **Case (T‑Int).** e = n. n is a value. ✓
- **Case (T‑True).** e = true. true is a value. ✓
- **Case (T‑False).** e = false. false is a value. ✓

- **Case (T‑Lt).** e = e1 < e2 with both sub‑expressions of type Int.
    The argument mirrors (T‑Add) using rules (E‑Lt2), (E‑Lt3) and (E‑Lt1). ✓
