DEFINE the wheel graph W_11 with hub node 0 and peripheral nodes 1-11 forming the cycle 1-2-...-11-1.
PROVIDE a 4-coloring assignment for each node of W_11 using colors labeled 1, 2, 3, 4 such that any two adjacent nodes receive different colors.
DEMONSTRATE that a 3-coloring is impossible for W_11 by proving that the odd peripheral cycle of length 11 together with the hub node forces the chromatic number to be 4.
